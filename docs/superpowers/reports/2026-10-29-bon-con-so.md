### 1b. Phân bố `need` trên `take` THẬT — 33–37 % dòng phải nén

**ĐO ĐƯỢC, và bản đầu của phép đo này VÔ NGHĨA — ghi lại để không ai viết lại như thế.**

Bản đầu đặt `takes = slots` (giả định "TTS dài bằng nói") rồi gọi
`need_i = take_i / max(slot_i, avail_i)`. Với `take_i == slot_i` thì `need_i <= 1` LUÔN ĐÚNG
(nếu `avail >= slot` thì `slot/avail <= 1`; nếu `avail < slot` thì `slot/slot = 1`), nên
`so_dong_phai_nen` luôn bằng 0 bất kể dữ liệu. Kiểm bằng tay:

```
takes == slots, co khe -> need = [0.4, 0.5, 1.0] | toc_do = [1.0, 1.0, 1.0]
takes == slots, khong khe  -> need = [1.0, 1.0, 1.0] | toc_do = [1.0, 1.0, 1.0]
```
